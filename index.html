Featured build · Scrut Automation

AI-assisted Trust Vault setup

Days → <15 min

Time for a new customer to set up their Trust Vault

I led this flow end to end: the React setup experience, the Node.js REST APIs behind it and the Python AI backend that does the heavy lifting. Progress streams to the browser as it happens, so a long AI job feels short.

  • Parallel LangGraph workflow with a context layer that pulls each tenant's compliance data from DynamoDB and their uploaded documents from S3.
  • DynamoDB schema for AI output across subtasks and workflows, partitioned by tenant, entity and subtask.
  • Server-sent events end to end, from backend endpoints to a real-time progress bar in React.
  • Serverless, event-driven execution on AWS Lambda with SQS triggers.
  • A branding pipeline that scrapes customer sites with BeautifulSoup for logos, favicons, privacy policies and terms, then has an LLM pick the right ones.
